# لوحة تحكم تطبيق كرامتي (Karamty Admin Dashboard) ⛪✨

لوحة تحكم إدارية احترافية ومتكاملة مبنية بأحدث التقنيات لمتابعة وإدارة كافة خدمات وأنشطة تطبيق كرامتي، مع تزامن لحظي وسحابي كامل مع قاعدة بيانات **Supabase** وتطبيق الموبايل (**Flutter**).

---

## 🌟 المميزات الرئيسية للوحة التحكم

1. **📊 لوحة القيادة والمؤشرات الحية (Executive Overview)**:
   - إحصائيات فورية لعدد الخدام، الأعضاء، طلاب مدارس الأحد، ورصيد صندوق الخدمة.
   - رسوم بيانية تفاعلية لمعدلات النشاط الأسبوعي ونسب الفئات المسجلة.
   - خلاصة أحدث المنشورات والتفاعل القادم من تطبيق الموبايل.

2. **👥 إدارة الخدام والمستخدمين (Servants & Members)**:
   - عرض وتصفية جميع الحسابات المسجلة.
   - تعديل الرتب (خادم، أمين خدمة، كاهن، مستخدم) وإدارة رصيد النقاط.
   - إمكانية إضافة مستخدم جديد وتصدير كشف البيانات إلى ملف **Excel/CSV**.

3. **🎓 مدارس الأحد وكشف الحضور والغياب (Sunday School & Attendance)**:
   - تقسيم المراحل العمرية (حضانة، ابتدائي، إعدادي، ثانوي، جامعيين وخريجين).
   - كشف حضور وغياب تفاعلي لكل أسبوع مع تحديد تاريخ الحصة وحساب نسب الحضور تلقائياً.
   - إضافة مخدومين جدد مع إمكانية **تعديل أو حذف أسماء المخدومين** من الكشف في أي وقت.

4. **💬 إدارة مجتمع إكسبلور والتفاعل (Community & Explore)**:
   - متابعة منشورات المستخدمين الحية وتفاعلاتهم (إعجابات وتعليقات).
   - حذف المنشورات أو التعليقات غير اللائقة.
   - **نشر إعلانات كنسية رسمية** تظهر فوراً ومثبتة في تطبيق الموبايل لكافة المستخدمين.

5. **📦 مخزن وعُهد الكنيسة (Church Inventory & Assets)**:
   - تصنيف الأجهزة الصوتية، الملابس والخدمة، الكتب، وأدوات المسرح والكشافة.
   - متابعة الكمية الإجمالية والمتاح للإعارة مع تنبيهات عند نفاد الكميات.

6. **💰 المالية وميزانية الخدمة (Service Budget & Subscriptions)**:
   - تسجيل ومتابعة الإيرادات والمصروفات والاشتراكات الشهرية والتبرعات.
   - حساب تلقائي لصافي رصيد الصندوق الحالي المتاح للخدمة.

7. **🎁 متجر النقاط والمكافآت (Points Store & Redemptions)**:
   - كتالوج المكافآت وهدايا التميز وسعر كل منها بالنقاط.
   - إدارة طلبات استبدال النقاط من المخدومين وتأكيد التسليم بضغطة زر.

8. **🔔 البث والإشعارات الفورية (Mobile Push Broadcast)**:
   - إرسال تنبيهات عاجلة تصل مباشرة إلى هواتف جميع المستخدمين والخدام عبر التطبيق.

---

## ⚡ التشغيل المحلي (Local Run)

الداش بورد تعمل حالياً وجاهزة على:
```bash
http://localhost:3001
```

لتشغيل السيرفر يدوياً في أي وقت:
```bash
cd dashboard
npm run dev
```

## 🚀 خطوات الرفع على GitHub و Vercel في دقيقة واحدة

### 1. الرفع على GitHub:
1. افتح موقع [GitHub.com](https://github.com/new) وأنشئ مستودع جديد باسم: `karamty-admin-dashboard`
2. في موجه الأوامر (Terminal) داخل مجلد `dashboard`، اكتب الأوامر التالية:
```bash
git remote add origin https://github.com/YOUR_USERNAME/karamty-admin-dashboard.git
git branch -M main
git push -u origin main
```
*(استبدل `YOUR_USERNAME` باسم حسابك على GitHub)*

### 2. النشر المباشر على Vercel:
1. ادخل على [Vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط على **"Add New Project"** ثم اختر مستودع `karamty-admin-dashboard`.
3. سيتعرف Vercel تلقائياً على إعدادات Vite وملف `vercel.json` المرفق.
4. اضغط **Deploy** وستحصل على رابط موقع عالمي سريع ومؤمن بشهادة SSL مجانية!
